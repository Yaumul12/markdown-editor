# Markdown Editor

Live markdown editor with split-pane preview and export to HTML.

## How to Use

**Step 1:** Open `index.html` in your browser.

**Step 2:** An onboarding tutorial appears on first visit. Click **Start Writing** (or Skip).

**Step 3:** Type markdown in the left pane using standard syntax:
- `# Heading` for headers
- `**bold**` for bold text
- `*italic*` for italic text
- `` `code` `` for inline code
- ` ```code block``` ` for code blocks
- `> quote` for blockquotes
- `- item` for lists
- `[text](url)` for links

**Step 4:** The right pane shows the rendered HTML preview in real-time as you type.

**Step 5:** Click **Load Example** to see a sample markdown document.

**Step 6:** Click **Copy HTML** to copy the rendered output to clipboard.

**Step 7:** Click **Download .md** to save the raw markdown as a file.

## Features
- Split-pane live preview
- Full markdown syntax support
- Copy rendered HTML
- Download as .md file
- Load example document
- Dark theme with monospace font

## Tech
HTML + CSS + JavaScript | No dependencies
